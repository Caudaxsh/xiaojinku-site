# 給 GPT 的單字卡 PDF 規則

這份規則和 App「匯入」頁的「複製提示詞（PDF 版）」是同一份（由 `scripts/build-rules-doc.mjs` 自動產生，測試會檢查兩邊一致）。

## 怎麼用

1. 在 App「匯入」按**複製提示詞（PDF 版）**，或直接複製下面整段。
2. 貼給 ChatGPT，最後接上這次要學的單字，一行一個，**最多 50 個**。
3. ChatGPT 交出 PDF 後下載，回 App「匯入」選擇這個 PDF。
4. 看預覽：每個單字都在、沒有黃色警告，再按匯入。

## 提示詞（照原樣貼給 GPT）

```
你要幫我製作「英文單字卡 PDF」。我會在最後列出單字，請為每個單字各做一張卡，全部放進同一個 PDF。
這個 PDF 會由我的網頁 App 用程式讀取，所以格式必須完全照下面做。

【PDF 規格】
1. A4 直式、單欄、純文字。字型必須完整顯示繁體中文和音標符號；如果有字變成空白或方塊，請換字型再做。
2. 不要頁首、頁尾、頁碼、浮水印、封面、目錄、圖片、表格、色塊。
3. 下面範例裡的 ##、###、「- 」這些符號，要「原樣印在 PDF 上」，不要轉成粗體、大標題或圓點。
4. 單字之間空一行，並單獨用一行寫 ---。單字順序和我的清單完全一樣。
5. 一個 PDF 最多 50 個單字，超過就拆成多個 PDF。
6. 做完後請自己檢查：把 PDF 的文字讀出來，確認單字數量和清單一致、沒有空白方塊或亂碼，有問題先修好再交給我。
7. 除了 PDF，只回覆一句「完成，共 N 個單字」，不要其他說明。

【每個單字的格式】（標題文字一律照範例，不要改字、不要換順序）
## Flagship ★★★★
音標：/ˈflæɡ.ʃɪp/
1. This is the company's flagship smartphone, with its most advanced features.
2. The brand opened a new flagship store in Taipei.
### 中文翻譯
1. 這是該公司的旗艦智慧型手機，搭載了最先進的功能。
2. 這個品牌在台北開了一間新的旗艦店。
### 意思
旗艦；旗艦級的
- （n.）品牌最具代表性、定位最高階的產品、店面或計畫
- （adj.）旗艦級的，最頂級的
### 常見搭配
- flagship product — 旗艦產品、主打產品
- flagship store — 旗艦店
- flagship model — 旗艦機型
- flagship program — 核心計畫、代表性計畫
- flagship university — 具代表性的核心大學
### 易混淆比較
- flagship — 品牌最具代表性、通常技術或定位最高階的產品
- premium — 高級的、高價位的，不一定是品牌最高階
- mainstream — 主流的，面向大多數消費者
### 詞性變化
- flagship (n.) — 旗艦
- flagship (adj.) — 旗艦級的
- flagship-level (adj.) — 旗艦級的
### 拆解記憶
flag（旗幟）＋ ship（船）＝ flagship（旗艦）
原本指艦隊中懸掛指揮官旗幟的主力艦，後來引申為品牌中最具代表性的產品。
### 最快記法：Flagship = 品牌拿來當門面的代表作
---

【內容規則】
1. 單字標題：英文單字寫小寫原形。片語照原樣寫，可替換的部分用括號，例如 base (something) on。標題後面接 1–5 顆「★」，代表這個字在日常與職場口說的實用程度（5 最高）。
2. 音標：Cambridge 字典的美式音標，寫成「音標：/…/」，放在標題的下一行。
3. 英文例句：剛好 2 句，各占一行，用 1. 2. 編號。自然、口語、日常或職場可用，長度約 8–20 個字，一定要包含這個單字（可以是變化形態）；片語要完整出現。每句寫成一行，不要自己在句子中間換行。
4. 中文翻譯：剛好 2 句，順序和英文例句一一對應，用 1. 2. 編號。
5. 意思：第一行只寫最核心的中文意思，不超過 20 個字，結尾不要加句號，多個意思用「、」或「；」隔開。如果想補充（其他詞性的意思、用法情境），每點一行，用「- 」開頭。
6. 常見搭配：5–8 項，每項一行：「- 英文搭配 — 中文意思」，中間用破折號「—」。
7. 易混淆比較（沒有容易混淆的字就整段省略）：每項「- 單字 — 差別說明」，要包含這個字本身。
8. 詞性變化：每項「- 單字 (詞性) — 中文」，詞性只寫 n. v. adj. adv. 這幾種。
9. 拆解記憶：字根、拆解或聯想，1–3 行。有公式時用「＋」「＝」連接。
10. 最快記法：寫成「### 最快記法：」後面直接接一句話。需要補充時，下面每點一行，用「- 」開頭。
11. 想補充別的內容時，可以自己新增「### 標題」段落，放在「最快記法」之前。
12. 全程不要使用 ①②③ 這類圓圈數字，也不要用 emoji；列點一律用「- 」，星星一律用「★」。

【我的單字清單】
（照這個順序，一個都不要漏，也不要自己加字）
```

## 每一條規則為什麼存在

| 規則 | 原因 | App 端的防護 |
|---|---|---|
| 不要頁首、頁尾、頁碼 | 這些文字會被當成單字內容讀進去 | 自動移除每頁重複的頁首頁尾與頁碼，並在匯入畫面告訴你移除了幾行 |
| 不要 ①②③、不要 emoji | PDF 字型常常沒有這些字，會變成空白或方塊，內容就遺失了 | 圓圈數字遺失時依序補回；方塊與亂碼會在匯入畫面標紅警告 |
| ##、###、「- 」要原樣印出 | 這些符號是 App 判斷「哪裡是新單字、哪一段是什麼」的依據 | 沒有這些符號時，仍會用「單字 ★★★」和段落標題文字去猜 |
| 每個單字固定 2 句例句 + 2 句翻譯 | 正面要放 2 句例句、背面對應 2 句翻譯 | 數量不一致會在預覽標黃色警告 |
| 「### 意思」第一行放最短的核心意思 | 這一行會變成卡片背面最大的標題字 | 其餘行會變成下方的補充條列 |
| 單字之間用 `---` 分隔，順序照清單 | 方便比對有沒有漏字 | 沒有分隔線也能靠標題切開；重複的單字會被標出 |
| 一份最多 50 字 | 太長 GPT 容易偷懶、後半段品質下降 | 無限制，但建議分批 |
| 要求 GPT 自己讀回 PDF 檢查 | 在你拿到檔案前先擋掉空白方塊與漏字 | 預覽仍會再檢查一次 |

## App 自動處理的情況（GPT 偶爾不照規則時）

- 音標在標題上一行、下一行、或寫在標題後面
- 標題寫成 `## Lovely ★★★★`、`## 1. Lovely (adj.)`、`**Lovely** ★★`、或只有 `Lovely ★★★`
- 全形數字與句號（１．）、各種圓點符號（● ○ ■ •）、不換行空格、零寬字元
- 「### 中文翻譯」黏在上一句英文後面
- 沒有「### 意思」標題，直接寫「單字：意思」或直接一段中文
- 自己多加的「### 其他標題」段落（會變成卡片背面的獨立區塊）
- 一句長句被 PDF 在頁面右緣自動換行，甚至跨頁

## 仍需要你看一眼預覽的情況

| 預覽訊息 | 代表什麼 | 怎麼辦 |
|---|---|---|
| 沒有英文例句／中文翻譯／中文意思 | 該單字缺這一段 | 請 GPT 補上那個單字再匯入 |
| 例句 N 句、翻譯 M 句，數量不一致 | 少了或多了一句 | 同上 |
| 單字名稱看起來不對 | 標題被當成單字，或單字被切錯位置 | 檢查 PDF 該段，或請 GPT 重做 |
| 同一批裡重複出現 | 同一個字出現兩次 | 只會保留第一筆 |
| 略過一段 | 有一段看不出是單字內容（例如 PDF 開頭的標題） | 通常可忽略 |
| PDF 讀不到文字 | PDF 是掃描圖片 | 改用「貼上版」提示詞，直接複製文字 |

## 匯入前自己檢查的 30 秒清單

1. 預覽顯示的單字數 = 你給 GPT 的單字數
2. 沒有黃色或紅色警告
3. 隨便點開 1–2 個字，確認背面各段落都在
