# 小金庫單字

個人專屬的英文單字複習網站（PWA）。純 HTML / CSS / JavaScript，沒有建置步驟。
iPhone 用 Safari「加入主畫面」後，就能像 App 一樣全螢幕、離線使用，不需要上架或審核。

## 卡片

- **正面**：單字、音標、發音按鈕、兩個英文例句（每句可單獨朗讀）。
- **背面**：中文意思，以及依顏色分段的例句翻譯、常見搭配、易混淆比較（A vs. B）、
  詞性變化、記憶方式（拆解記憶 + 最快記法）、同義／反義、文法補充。
  頂端有段落標籤可直接跳到想看的部分，評分按鈕固定在畫面底部。

### 發音來源

單字依序嘗試：**Cambridge Dictionary 美式錄音 → Google 翻譯語音 → 手機內建英文語音**。
例句與搭配詞沒有 Cambridge 錄音，直接用 Google → 手機內建語音。
音標若內容沒提供，會自動向 dictionaryapi.dev 查詢一次並存下來。

> Cambridge 的錄音網址是依規則推測的，沒有收錄或網址規則不同的字會自動改用 Google。
> 這兩個都是非官方用法，日後若失效會退回手機內建語音。

## 星級與複習

第一次學到這個字時，翻到背面選星級（會顯示 ChatGPT 標的 ⭐ 實用度當參考）：

| 星級 | 複習 | 之後 |
|---|---|---|
| ★★★ 最重要 | 第 5 天、第 10 天各一次 | 學完 |
| ★★ 重要 | 第 10 天一次 | 學完 |
| ★ 艱深少用 | 不再複習 | 學完 |

答「忘了」會隔天再出現，並重做那一次複習。間隔設定在 `js/srs.js` 的 `LADDERS`。
單字庫可以篩選後進入**練習模式**，練習不會影響排程。

## 匯入單字

1. 「匯入」→ **複製 AI 提示詞**，貼給 ChatGPT，後面接上這次要學的整批單字（40–50 個也可以）。
2. ChatGPT 回覆後，**全選複製貼上**，或把回覆**存成 PDF 上傳**。
3. 看預覽確認每個字都切對了 → 匯入。每天出的新字數可在設定調整（預設 20）。

PDF 在手機上直接解析（內建 pdf.js），會自動去掉頁碼、把被換行切斷的句子接回來。
掃描成圖片的 PDF 讀不到文字，請改用貼上。同一個字再匯入只會更新內容，不影響進度。

格式範例見 `samples/flagship.txt`：每個字以「單字 ⭐⭐⭐」開頭，
段落標題可用：中文翻譯、意思、常見搭配、A vs. B、詞性變化、拆解記憶／記憶方式、
最快記法、同義詞／反義詞、注意文法／補充。字與字之間的 `---` 可有可無。

## 資料存在哪裡

- 存在**這支手機、這個網址專屬的瀏覽器資料庫（IndexedDB）**，不會上傳到 GitHub 或任何伺服器。
- iPhone 上「加入主畫面」的 App 和 Safari 是**兩個分開的儲存空間**，請一律從主畫面開啟、匯入。
- 刪掉主畫面 App、清除網站資料或換手機，資料就會消失。請在「設定 → 匯出備份」定期存到「檔案」或 iCloud Drive。

## 發佈（GitHub Pages）

1. 把分支合併到 `main`。
2. Settings → Pages → `Deploy from a branch` → `main` / `(root)`。
3. 網址為 `https://<帳號>.github.io/xiaojinku-site/`，不需任何審核。

## 開發

```sh
python3 -m http.server 8000        # 開 http://localhost:8000
node --test tests/parser.test.mjs tests/srs.test.mjs
```

修改檔案後把 `sw.js` 的 `CACHE` 版本號加一，已安裝的手機才會更新。

| 檔案 | 用途 |
|---|---|
| `js/parser.js` | 解析貼上或 PDF 的文字、AI 提示詞 |
| `js/pdf.js` | PDF 文字擷取與斷行修復 |
| `js/audio.js` | 發音來源鏈、音標查詢 |
| `js/srs.js` | 星級複習排程 |
| `js/store.js` | 本機儲存（IndexedDB，備援 localStorage） |
| `js/app.js` | 介面與互動 |
| `vendor/pdfjs/` | Mozilla pdf.js 6.3.289（Apache-2.0） |
