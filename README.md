# Cash Volcab

個人專屬的英文單字複習網站（PWA）。純 HTML / CSS / JavaScript，沒有建置步驟。
iPhone 用 Safari「加入主畫面」後，就能像 App 一樣全螢幕、離線使用，不需要上架或審核。

## 圖示系統

線性圖示，24×24 格線、描邊 1.75、圓潤線端；線條深墨綠 `#28675F`，點綴薄荷綠 `#83CBB8`、珊瑚粉 `#F4B29A`、奶油黃 `#E9DCA8`。
學習相關的圖示依設計參考圖繪製，一般功能改自 [Lucide](https://lucide.dev)（ISC）。用法：`icon('translate', { size: 20 })`。
完整一覽打開 `icons.html`。方塊拼貼只用在卡片背面頂端的四個分類標籤。

## 卡片

- **正面**：單字、音標、發音按鈕、兩個英文例句（每句可單獨朗讀）。
- **背面**：中文意思，以及依顏色分段的例句翻譯、常見搭配、易混淆比較（A vs. B）、
  詞性變化、記憶方式（拆解記憶 + 最快記法）、同義／反義、文法補充。
  頂端有段落標籤可直接跳到想看的部分，評分按鈕固定在畫面底部。

### 發音來源

單字依序嘗試：**Cambridge Dictionary 美式錄音 → Google 翻譯語音 → 手機內建英文語音**。
例句與搭配詞沒有 Cambridge 錄音，直接用 Google → 手機內建語音。
音標若內容沒提供，會自動向 dictionaryapi.dev 查詢一次並存下來。

> Cambridge 的錄音網址是依規則推測的，沒有收錄或網址規則不同的字會自動改用 Google。
> 這兩個都是非官方用法，日後若失效會退回手機內建語音。

## 學習規則（以「學習日」計算）

「學習日」＝你真的有學習（評分過卡片）的那一天，**沒學的日子不算**。所以哪天沒打開，所有複習會整體順延，不會堆積。

1. 匯入的單字，會在你**下一次開始學習**時出現。第一次看到時翻到背面選星級。
2. ★★★ 最重要：從那天起算，**第 3 個學習日**再複習一次。這一次的卡片**正面是深色**，並標示「第 2 次複習」。
3. ★★、★：第一次學完就結束，不再安排複習。
4. 答「忘了」：這一輪會再出現一次，下個學習日再複習。

間隔設定在 `js/srs.js` 的 `LADDERS`（單位是學習日，目前 `{3: [3], 2: [], 1: []}`）。
單字庫可以篩選後進入**練習模式**，練習不會影響排程。

## 首頁寵物

寵物直接站在首頁的標題文字、連續天數、三個統計卡、開始按鈕和面板的上緣，在上面走動、待機，並在框框之間跳過去。牠在一個可點穿的圖層上，只有牠本身能被點到，版面不會因牠移動。

- **全部自己動，不需要點**：靜靜待機一兩秒後，自己決定下一個動作 — 走、跑、跳、思考（問號、燈泡）、睡一小覺（睡 10–17 秒後自己醒來），不會連續重複同一個，睡覺和跳躍有冷卻時間。也會從一個框框跳到另一個。點牠只是額外的互動（跑、跳、思考、舉單字卡）。
- 完成今天的學習或匯入成功，下次回到首頁時會慶祝；忘記的字太多時改為打氣。
- 到「設定 → 首頁寵物」可以關閉、開「安靜模式」（只在你點牠時反應）。系統開啟「減少動態效果」時只會靜靜坐著。畫面不可見或切到背景時暫停。
- 內建角色在 `pet/goku.petpack.json`（一個檔案：sprite sheet + 動作表，目前有待機和走路）。也可以在「設定 → 載入角色素材」載入自己的素材檔取代。`pet.html` 可預覽每個動作。
- 寵物系統與角色無關：換一個符合格式的素材檔就能換角色（格式見 `js/pet/pack.js`）。
- 角色是參考《七龍珠》孫悟空製作的同人作品，版權屬原作者；若公開網站被要求下架，刪掉 `pet/goku.petpack.json` 即可，網站會自動沒有寵物。

## 匯入單字

1. 「匯入」→ **複製提示詞（PDF 版）**，貼給 ChatGPT，最後接上這次要學的單字（一次最多 50 個）。
2. ChatGPT 交出 PDF 後下載，回 App 選擇這個 PDF。想直接複製文字的話，用「貼上版」提示詞。
3. 看預覽確認每個字都切對了、沒有警告 → 匯入。每天出的新字數可在設定調整（預設 20）。

給 GPT 的完整規則、每條規則存在的原因、App 能自動容忍和仍需人工留意的情況，
都在 [`docs/gpt-pdf-rules.md`](docs/gpt-pdf-rules.md)（由 `scripts/build-rules-doc.mjs` 從 App 內的提示詞產生）。

PDF 在手機上直接解析（內建 pdf.js），做了這些防護：

- **三種載入方式依序嘗試**：正常載入 → 把檔案重新包成 Blob 再載入（主機或瀏覽器拒絕檔案類型時）→ 完全不用 Web Worker（瀏覽器跑不起 Worker 時）。每一步 25 秒沒反應就換下一種。
- **失敗時說明原因**：密碼保護、不是完整的 PDF、掃描圖片沒有文字、載入元件失敗，各有明確說明；畫面上有「複製診斷資訊」，貼給我就能查（含每一種方式的錯誤、瀏覽器版本）。
- **用檔頭判斷是不是 PDF**，不看檔名。iPhone 的「檔案」有時會給沒有副檔名的檔案。
- **缺字**：字型沒有的字（例如罕用字「瀕」）在 PDF 裡本來就是空白，不可能讀回來。會用「□」標記並在畫面上列出是哪一行，請在文字框補上。圓圈數字 ①② 則會依序補回。
- 自動去掉每頁重複的頁首頁尾與頁碼、把被自動換行切斷的長句接回來（包含跨頁）。掃描成圖片的 PDF 讀不到文字，請改用貼上。
- 文字檔支援 UTF-16 和 Big5。

同一個字再匯入只會更新內容，不影響進度；匯入錯了可以「復原這次匯入」。

## 測試後清除

「設定 → 測試與清除」（每個按鈕都要按兩次才會執行）：

- **復原上一次匯入**：刪掉那次新增的字，並還原被更新的字
- **重設學習進度（保留單字）**：所有單字回到「待分級」，連續天數歸零
- **清除所有單字與進度**

## 資料存在哪裡

- 存在**這支手機、這個網址專屬的瀏覽器資料庫（IndexedDB）**，不會上傳到 GitHub 或任何伺服器。
- iPhone 上「加入主畫面」的 App 和 Safari 是**兩個分開的儲存空間**，請一律從主畫面開啟、匯入。
- 刪掉主畫面 App、清除網站資料或換手機，資料就會消失。請在「設定 → 匯出備份」定期存到「檔案」或 iCloud Drive。

## 發佈（GitHub Pages）

1. 把分支合併到 `main`。
2. Settings → Pages → `Deploy from a branch` → `main` / `(root)`。
3. 網址為 `https://<帳號>.github.io/xiaojinku-site/`，不需任何審核。

## 開發

```sh
python3 -m http.server 8000        # 開 http://localhost:8000
node --test tests/parser.test.mjs tests/srs.test.mjs tests/brain.test.mjs
```

修改檔案後把 `sw.js` 的 `CACHE` 版本號加一，已安裝的手機才會更新。

| 檔案 | 用途 |
|---|---|
| `js/parser.js` | 解析貼上或 PDF 的文字、AI 提示詞 |
| `js/pdf.js` | PDF 文字擷取、頁首頁尾移除、斷行修復 |
| `js/audio.js` | 發音來源鏈、音標查詢 |
| `js/srs.js` | 學習日複習排程 |
| `js/pet/` | 寵物：`sprite.js` 播放影格、`brain.js` 決定做什麼、`pet.js` 舞台與事件、`pack.js` 素材檔格式 |
| `pet.html` | 寵物動作預覽頁 |
| `js/store.js` | 本機儲存（IndexedDB，備援 localStorage） |
| `js/app.js` | 介面與互動 |
| `js/icons.js` | 圖示系統（統一規格的 SVG 圖示元件） |
| `icons.html` | 圖示展示頁，所有圖示、尺寸、色彩一覽 |
| `docs/gpt-pdf-rules.md` | 給 GPT 的 PDF 規則（自動產生） |
| `vendor/pdfjs/` | Mozilla pdf.js 6.3.289（Apache-2.0）。檔名用 `.js` 而不是 `.mjs`：有些主機會把 `.mjs` 當成非 JavaScript 而被瀏覽器拒絕載入 |
